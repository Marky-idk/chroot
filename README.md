📦 CHROOT // STORE


Welcome to the official CHROOT Store repository. This is a high-performance, minimalist web interface designed for the distribution of system-themed apparel and digital assets.


🛠 Tech Stack
Frontend: HTML5, CSS3 (Flexbox/Grid), JavaScript (Vanilla).


Design Language: Minimalist Terminal Aesthetic (JetBrains Mono + Jakarta Sans).


Architecture: Optimized for Linux environments and mobile responsiveness.


🚀 Deployment
This project is currently live via GitHub Pages.
